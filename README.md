# Racing game in Bevy

All phyiscs in the game are coded. The game engines phyiscs are not being used.
This game is using Bevy + Rust to run.

Play here: [https://bigb132.github.io/racing_game](https://bigb132.github.io/racing_game) (might lag on slower devices)

The game is not finished yet, but you can drive arround on the map and try some of the game's phyiscs.

You can also build it yourself using

```
cargo build
```
